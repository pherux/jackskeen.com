# JackSkeen.com Rebuild

## Purpose

Rebuild `jackskeen.com` as a modern, premium, content-driven website that positions Dr. Jack Skeen as an authority, presents **The Roadmap** as the flagship commercial offer, preserves and improves the value of the existing content library, and creates a strong foundation for traditional SEO and AI-assisted search/discovery.

This repository is intended to be built with Codex using the requirements and task plan in `/docs`.

## Primary goals

1. Replace the current WordPress/PHP site.
2. Create a professional, modern, simple design with distinct personality.
3. Make The Roadmap the primary commercial journey.
4. Present Jack's expertise, ideas, books, podcast, videos, and success stories as a coherent body of work.
5. Migrate existing articles without unnecessary SEO loss.
6. Make future publishing easy for non-developers.
7. Optimize the site for crawlability, structured data, topical authority, and AI-search discoverability.
8. Maintain excellent performance and accessibility.
9. Deploy on Vercel.

## Recommended stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Sanity CMS
- Vercel
- `next/image`
- `next/font`
- Server Components by default
- GA4
- Google Search Console
- Bing Webmaster Tools

## Content philosophy

The site should behave as three connected products:

- **Authority platform:** Jack Skeen's identity, credentials, philosophy, and body of work.
- **Commercial platform:** The Roadmap and related services.
- **Knowledge library:** Articles, videos, podcast episodes, and evergreen topic pages.
