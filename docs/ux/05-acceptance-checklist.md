# Wireframe Acceptance Checklist

## Structure

- [x] Homepage prioritizes problem and solution before detailed process.
- [x] Roadmap has clear fit, problem, method, outcomes, proof, FAQ, and CTA slots.
- [x] About supports authority without unsourced credentials.
- [x] Article preserves legacy metadata and URL requirements.
- [x] Insights supports content formats and the eight-topic system.
- [x] Topic hubs require original value before indexation.
- [x] Podcast and video listing/detail states are specified.
- [x] Success Stories withholds unapproved proof.
- [x] Start and Contact include complete state requirements.
- [x] Mobile navigation behavior is specified.

## Interaction and conversion

- [x] One global primary CTA and destination are defined.
- [x] Secondary and contextual CTAs are distinguished.
- [x] Five primary user journeys and failure states are mapped.
- [x] Internal-link and breadcrumb contracts are defined.
- [x] Related-content selection rules are defined.
- [x] Responsive transformations are specified for all required templates.

## Content, SEO, and accessibility

- [x] No claims, credentials, testimonials, prices, or integrations were invented.
- [x] Placeholder/noindex requirements are preserved.
- [x] Legacy article URL preservation is carried forward.
- [x] Thin category/tag structures are excluded.
- [x] Keyboard, focus, touch-target, labels, error, and reduced-motion requirements
  are represented.

## Build-entry gate

Visual implementation may proceed with placeholders, but production readiness still
requires approved source material and the dependencies in the content approval
register. Forms must not be enabled and placeholder pages must not be indexed before
their complete requirements are met.
