# Visual Design Foundation

## Status

EPIC 4 is complete as a source-controlled design foundation. It uses the selected
homepage reference, the approved UX specification, and the current responsive
implementation. No Figma account is required.

Open [`review-board.html`](./review-board.html) for the visual board, or read the
implementation specification in [`design-system.md`](./design-system.md).

## Direction

The system is premium, editorial, calm, and human. Deep Atlantic blue is the brand
anchor; warm paper backgrounds carry most reading surfaces; clay is a restrained
action accent. Cormorant Garamond creates editorial hierarchy and Manrope handles
navigation, labels, metadata, and body copy.

The selected homepage reference remains the composition source of truth. The color
adjustment in this phase is intentional: dark green-black surfaces move to a deeper
blue while the light surfaces become cleaner and brighter. The approved Jack
photography and problem/solution emphasis remain unchanged.

## Guardrails

- Do not turn the system into generic navy-and-gold executive coaching.
- Do not add gradients as decoration; the hero edge fade is the sole functional
  exception because it joins copy and photography.
- Do not use excessive cards, icons, rounded containers, shadows, or animation.
- Do not publish placeholder proof, credentials, prices, or integrations.
- Preserve the approved photography crop and its edge diffusion.
